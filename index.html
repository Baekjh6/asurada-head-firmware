Installs the desk figure's firmware on the Waveshare ESP32-S3-Touch-AMOLED-1.75 round display board straight from your browser. No software to install.Waveshare ESP32-S3-Touch-AMOLED-1.75 원형 디스플레이 보드에 탁상 피규어 펌웨어를 브라우저에서 바로 설치합니다. 따로 설치할 프로그램은 없습니다.

Before you start시작하기 전에
  • A PC with Chrome or Edge (a phone is not recommended).
  • A USB data cable (a charge-only cable will not work).
  • Plug the cable into the USB socket on the stand. This works when its four wires (5V, GND, D+, D-) are connected to the display board as in the assembly guide. Otherwise use the display board's own USB-C port: the screen bezel is held by magnets and comes off.
  • Close any serial monitor or other program that uses the board's serial port.
  • Chrome 또는 Edge가 있는 PC (휴대폰은 권장하지 않습니다).
  • USB 데이터 케이블 (충전 전용 케이블은 안 됩니다).
  • 케이블은 받침대의 USB 소켓에 꽂습니다. 조립 설명서대로 선 4가닥(5V, GND, D+, D-)을 화면 보드에 연결했을 때 됩니다. 그렇지 않으면 화면 보드 자체의 USB-C 포트를 씁니다. 화면 테두리는 자석으로 붙어 있어 떼어 낼 수 있습니다.
  • 보드의 시리얼 포트를 쓰는 다른 프로그램(시리얼 모니터 등)은 닫아 둡니다.
This browser cannot install firmware. Open this page in Chrome or Edge on a PC.이 브라우저에서는 설치할 수 없습니다. PC의 Chrome 또는 Edge에서 이 페이지를 여세요. Installing only works on an HTTPS page. Open this page from its https:// address.설치는 HTTPS 주소에서만 됩니다. https:// 주소로 이 페이지를 여세요.

Steps설치 순서

  1. Connect the figure to your PC with the USB cable.
  2. Click Install firmware and choose the new serial port that appears when you plug the figure in.
  3. If asked, choose whether to erase the device first. For a first install, erasing is recommended; it also removes the saved volume and servo settings. Then confirm and wait until it says the installation is complete. Do not unplug the cable. It can take a few minutes.
  4. The head restarts and shows four green eyes.
  1. 피규어를 USB 케이블로 PC에 연결합니다.
  2. 펌웨어 설치를 누르고, 피규어를 꽂았을 때 새로 생기는 시리얼 포트를 고릅니다.
  3. 기기를 먼저 지울지 물으면 선택합니다. 처음 설치라면 지우기를 권장하며, 저장된 볼륨과 서보 설정도 같이 지워집니다. 확인한 뒤 설치가 끝났다는 안내가 나올 때까지 기다립니다. 케이블을 뽑지 마세요. 몇 분 걸릴 수 있습니다.
  4. 머리가 다시 시작하고 초록 눈 4개가 나옵니다.

Sounds: add your own소리: 직접 넣기

No sound files are included. Without a card the figure runs silently and every screen still works.   • Format: 16-bit PCM WAV, mono or stereo, 8 kHz or higher. The firmware converts it to 16 kHz mono while playing. MP3 does not play.
  • The screens run on their own timing (the lengths above), so a sound of about the same length fits best.
  • Use sounds you made yourself or have the right to use.
  • 형식: 16비트 PCM WAV, 모노 또는 스테레오, 8 kHz 이상. 펌웨어가 재생하면서 16 kHz 모노로 바꿉니다. MP3는 재생되지 않습니다.
  • 화면은 정해진 시간(위 표의 길이)으로 움직이므로, 비슷한 길이의 소리가 잘 맞습니다.

If something goes wrong잘 안 될 때

  • The port list is empty: use a data cable and another USB port. If it still does not show, unplug the cable, hold the switch on the stand (it is wired to the board's BOOT pin) while plugging it in, then try again.
  • The install stops or fails: unplug and reconnect, close other programs that use the port, and try again, this time with erasing turned on.
  • The screen shows SETUP ERROR: the board was not written completely. Install again from this page with erasing turned on.
  • No suitable browser: install with a PC tool instead. See README.md (esptool or the Espressif Flash Download Tool) and the files in firmware/.
  • 포트 목록이 비어 있을 때: 데이터 케이블과 다른 USB 포트를 써 보세요. 그래도 안 보이면 케이블을 뽑고, 받침대의 스위치(보드의 BOOT 핀에 연결되어 있습니다)를 누른 채로 꽂은 뒤 다시 시도합니다.
  • 설치가 멈추거나 실패할 때: 케이블을 뽑았다 다시 꽂고, 포트를 쓰는 다른 프로그램을 닫은 뒤, 이번에는 지우기를 켜고 다시 시도합니다.
  • 화면에 SETUP ERROR가 나올 때: 보드에 다 써지지 않은 것입니다. 이 페이지에서 지우기를 켜고 다시 설치합니다.
  • 쓸 수 있는 브라우저가 없을 때: PC 도구로 설치합니다. README.md(esptool 또는 Espressif Flash Download Tool)와 firmware/의 파일을 보세요.
